# Blissful Beauty Cosmetics

Blissful Beauty Cosmetics is a modern online cosmetics shopping website developed using PHP and MySQL. The platform allows customers to browse beauty products, manage their shopping cart, create accounts, place orders, and explore various cosmetic collections through a user-friendly interface.

## Live Demo

Website: https://blissfulbeauty.infinityfree.me/

## Features

* User Registration and Login
* Product Browsing and Search
* Product Categories
* Wishlist Management
* Shopping Cart Functionality
* Secure Checkout Process
* Order Management
* User Profile Management
* Responsive Design
* Contact Us Page
* Product Search System

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Akshavahora/blissful-beauty-cosmetics.git
```

2. Move the project folder to your web server directory.

3. Create a MySQL database.

4. Import the provided SQL file into MySQL.

5. Configure database credentials in:

```php
dbconnection/connection.php
```

6. Start Apache and MySQL.

7. Open the project in your browser.

## Database Configuration

Update the database connection settings:

```php
$host = "localhost";
$username = "your_username";
$password = "your_password";
$database = "your_database";
```
